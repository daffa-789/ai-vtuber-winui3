## Jebakan yang sudah ketemu

- **`filepath.Clean` di Windows mengubah `/` jadi `\`.** Pemeriksaan "path masih di
  dalam root" di `sajiStatis` gagal kalau root ditulis dengan `/`, sehingga SEMUA
  berkas statis 404 walau filenya ada. Solusi: `root = filepath.Clean(root)` sebelum
  perbandingan. Sudah ada tesnya di `sidecar/internal/server/static_test.go`.
- `tsconfig.json` yang dipindah harus memperbaiki path `extends` (renderer kini butuh
  `../../../tsconfig.base.json`). Kalau salah, `vue-tsc` membanjiri error "Cannot find
  name 'Map'" karena tidak ada satupun compilerOptions yang kewaris.
- `curl` di lingkungan ini lewat proxy: harus `curl --noproxy '*'` untuk menguji
  `127.0.0.1`, dan `/tmp` tidak bisa dipakai untuk log proses latar — pakai berkas
  di dalam workspace.
- Mode tiruan: `VTUBER_STUB=ya`. Aplikasi terkemas tanpa `.env` atau tanpa GGUF di
  `model/` otomatis masuk mode ini.
